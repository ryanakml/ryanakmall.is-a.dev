# Phase 05 — Visual QA, Refinement & Launch Preparation

**Enter:** working production build, approved direction. **Exit:** quality-checked site with transparent limitations and explicit user-controlled public launch.

Use the installed Taste Skill's actual browser-inspection and screenshot-refinement procedure. Use Playwright or an equivalent verified browser runner for repeatable interaction tests and evidence. Check representative pages and interaction states at desktop (~1440px), tablet (~768px) and mobile (~390px).

Inspect: typography, spacing/rhythm, hierarchy, color contrast, image crops, mobile overflow, navigation, dead links, keyboard/focus, reduced motion, browser errors, layout consistency, responsive behavior, metadata and content accuracy. Run relevant typecheck, lint/test and production build commands. Repair material defects; reinspect and capture current screenshots. Only establish stable visual-regression baselines **after** design approval. Distinguish verified checks from checks that could not run.

Deliver:

- Working production build and source code.
- Current screenshots and concise QA report.
- Brief summary of visual refinements and outstanding limitations.
- Deployment/maintenance instructions and preview configuration where allowed.
- Final content/fact review for public claims.

**Deployment gate:** preparation is allowed within current permissions; do not purchase a domain, push to a public remote, expose a live site, or publish without direct approval. Ask before taking any public-launch action. Do not imply the site is already deployed.
